# Figure 2 source workflow

This document identifies the analytical and visualization sources used to
generate the current Figure 2 and its associated supplementary analyses.

The workflow is described by scientific content rather than by fixed panel
letters because the final figure layout may change.

## Spatial coexpression network

Sources:

- `scripts/figure2/01_prepare_wgcna_input.R`
- `scripts/figure2/02_build_wgcna_network.R`

These operations prepare the final annotated spatial-expression object,
construct the signed spatial coexpression network, identify modules `SM_1`
through `SM_6`, and calculate harmonized module eigengenes and connectivity.

## Differential module activity

Source:

`scripts/figure2/03_bis_analyze_differential_module_eigengenes_donor_level.R`

This operation averages harmonized spot scores within each donor, then compares
independent donor means in F1, F2, F3 and F4 with Healthy (F0) using two-sided
Wilcoxon rank-sum tests. BH correction covers six modules within each contrast.
Effects are differences between equally weighted mean donor scores. The chosen
ME source, donor counts, module assignments and input checksum are exported.
It supplies the final inference without rebuilding the network. Historical spot-level
comparisons remain in `scripts/figure2/03_analyze_differential_module_eigengenes.R` for traceability.

Final manuscript lollipop formatting is included in step 03_bis itself:
wrapped module labels, right alignment, 7 mm asterisks and an 11.5 x 7 inch canvas.
The volcano is also generated by that script. Statistical values are unchanged.
See the Figure 2 README for output locations and commands.

## Module membership and functional interpretation

Sources:

- `scripts/figure2/04_export_module_tables_and_run_enrichr.R`
- `scripts/figure2/05_generate_functionally_colored_hub_networks.R`
- `resources/figure2/functional_subcategories.tsv`

These sources export module and hub-gene tables, perform EnrichR analysis and
generate the six functionally annotated hub-gene networks.

## PCSK7 and PNPLA3 same-module ego networks

Sources:

- `scripts/figure2/05_bis_build_ego_networks.R`
- `resources/figure2/ego_network_functional_context_annotations.tsv`

This analysis uses the regenerated Figure 2 network and TOM workspace. Since
`GetTOM()` returns TOM dissimilarity, edge weights and rankings use
`TOM_similarity <- 1 - GetTOM_output`. Each index gene retains the genuine top
20 neighbours ranked by descending TOM similarity within its own module
(PCSK7: SM_1; PNPLA3: SM_3). No functional gene is force-included.

The annotation table assigns biological-context categories to selected true
neighbours; unannotated genes are labelled `Other`. It does not alter rankings.
This analysis was moved from Figure 4 step 06 to Figure 2 step `05_bis`.
Calculations and plotting settings are unchanged; new figure filenames use
`Fig2_` and gene names. Legacy `11_` table/log prefixes and F/G export identifiers
are retained for traceability and do not assign current manuscript panels.

## Harmonized module-eigengene visualizations

Sources:

- `scripts/figure2/06_plot_harmonized_module_eigengenes_and_celltype_associations.R`
- `scripts/figure2/07_generate_supplementary_wgcna_umaps.R`

These operations generate the spatial-domain hME dot plot, 24-sample hME maps,
hME-cell-type association heatmap, module-gene UMAP and harmonized-ME feature
maps.

## Supplementary donor-pseudobulk GSEA

Source:

`scripts/figure2/08_run_supplementary_stage_gsea.R`

This independent supplementary analysis:

- reads raw counts from the `Spatial` assay of the final annotated Seurat object
- aggregates counts within each of the 24 donors
- applies expression filtering, TMM normalization and limma-voom modelling
- compares F1, F2, F3 and F4 with F0
- ranks the complete expression-filtered gene list by moderated t-statistic
- performs seeded preranked GSEA using MSigDB H, C2, C3 and C5
- generates MDS and voom diagnostics and four all-significant Hallmark plots
- records parameters, database and package versions, checksums and session data

No individual-gene significance filter is applied before GSEA. This operation
does not use the WGCNA network object and is analytically independent of
hdWGCNA.

## Final Figure 2 audit

Validation source:

`scripts/figure2/09_validate_figure2_outputs.R`

This checks the public source files, WGCNA outputs, supplementary UMAPs,
donor-pseudobulk GSEA outputs, execution records and recorded checksums. It
checks output completeness and internal consistency without performing new
biological analysis.

## Generated outputs and records

Generated results are written under `results/Fig2_WGCNA/` and
`results/Fig2_GSEA/` and are not committed to GitHub. Compact execution records
are stored under `reproducibility_logs/Fig2_WGCNA/` and
`reproducibility_logs/Fig2_GSEA/`.

## Integrity manifest

`FIGURE2_SHA256.txt` records the SHA-256 checksums of the public Figure 2
documentation, scripts and static reference table. From the reproducibility
root, run:

```bash
shasum -a 256 -c FIGURE2_SHA256.txt
```
