# FLINC spatial transcriptomics analysis

Analysis code for the FLINC human liver spatial-transcriptomics study across
healthy liver and MASLD fibrosis stages. The manuscript workflow is organized
directly at this repository's root.

## Final manuscript analyses

- **Donor-level differential module eigengenes:**
  `scripts/figure2/03_bis_analyze_differential_module_eigengenes_donor_level.R`.
  Spot-level scores are averaged within each donor and module. Each fibrosis
  stage is compared with Healthy using an unpaired, two-sided Wilcoxon test,
  with BH correction across the six modules within each contrast. Final plot
  formatting is included in this script. The companion `03` script is retained
  as the explicitly labelled historical spot-level comparison; use `03_bis`
  for the manuscript's donor-level inference.
- **SM_1 and SM_6 secreted-factor profiles:**
  `scripts/figure4/11_plot_SM1_SM6_selected4_BH30.R`.
  Donor-level Spearman tests are calculated for 30 genes per module, with BH
  correction separately within each module. Four selected genes per module are
  displayed in matched 2×2 panels. Numeric q values are retained in the exported
  tables; plot labels use the applicable q-value thresholds.
- **Jian Wu's STRIDE scripts:** `scripts/deconvolution/jian_original/`.
  Their original contents and attribution are preserved. See the deconvolution
  guide for required inputs and original-path assumptions.

## Workflow and inputs

The main workflow is preprocessing/integration → spatial-domain clustering and
annotation → figure-specific analyses. Deconvolution fractions are an input to
the main workflow. The source maps provide details:

- [Deconvolution source workflow](DECONVOLUTION_SOURCE_WORKFLOW.md)
- [Figure 1 source workflow](FIGURE1_SOURCE_WORKFLOW.md)
- [Figure 2 source workflow](FIGURE2_SOURCE_WORKFLOW.md)
- [Figure 3 source workflow](FIGURE3_SOURCE_WORKFLOW.md)
- [Figure 4 source workflow](FIGURE4_SOURCE_WORKFLOW.md)

Required local inputs include sample metadata, Space Ranger outputs, the matching
STRIDE fraction matrix, and the analysis objects described in each guide. These
human-participant data and large generated objects are not included here.
Their availability is governed by the manuscript's data-availability statement.

The final secreted-factor script is a guarded rerun: it also requires saved
validation manifests and earlier SM_1/SM_6 exports. Those artifacts are not
generated by every numbered step and are not included in this repository.
See [the exact requirements](scripts/figure4/README.md#validation-inputs-required-for-reproducibility).

## Running the code

Read the relevant guide before execution. The scripts preserve the reference
Mac analysis configuration. Several scripts contain machine-specific paths;
the repository reorganization does not make all scripts portable. Adjust the
documented input/root paths to the local installation. Where supported, set
`FLINC_REPRO_ROOT` to the workflow root. Historical commands showing
`/Users/jianwu/Documents/FLINC/Jeremie/Reproducible_code` describe the original
local analysis folder, not an additional folder required on GitHub.

The R Markdown file in `scripts/source_history/` is an active dependency of
`scripts/analysis/02_cluster_annotate_and_characterize_spatial_domains.R`.
Do not remove it merely because its folder is named `source_history`.

Software-version and session-information records are retained under
`reproducibility_logs/`. Other historical run logs, donor metadata and generated
results remain outside this code repository. Paths to such output files in the
guides describe locally generated artifacts, not files bundled in this checkout.

## Integrity and scope

From the repository root, check the source manifests with:

```bash
shasum -a 256 -c FIGURE1_SHA256.txt
shasum -a 256 -c FIGURE2_SHA256.txt
shasum -a 256 -c FIGURE3_SHA256.txt
shasum -a 256 -c FIGURE4_SHA256.txt
shasum -a 256 -c DECONVOLUTION_SHA256.txt
```

This repository contains a fresh snapshot of the selected workflow, not the
previous repository's Git history or its unrelated legacy code/data/figures
folders. Scripts and static scientific resources were copied without changing
their calculations. Documentation and source-file checksums were updated for
the root layout. The migration did not rerun the biological analyses.
