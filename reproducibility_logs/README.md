# Software environment records

These files record R and package versions from the reference analysis runs.
Numerical source tables are provided separately under [resources/](../resources/README.md).

[Figure 4](figure4/README.md) includes software environment records for PROGENy,
DoRothEA and the final BH30 secreted-factor profiles. The saved records cover selected
runs; they are not a complete execution log for every script.
